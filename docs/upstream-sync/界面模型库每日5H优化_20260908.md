## Integration Map

| 子系统 | 调用链 / 数据 | 本次行为 |
|---|---|---|
| 页面宽度 | AppLayout → TablePageLayout → DataTable → 账号表 | 工具栏换行，固定表格可收缩，按容器宽度折叠次要列，保留列偏好 |
| 账号详情 | 账号响应 extra → 详情弹窗 | 展示完整账号信息、5H 执行结果及重试时间，不展示凭据 |
| 时间设置 | 每日5H弹窗 → 原 GET/PUT settings → settings JSON | trigger_time，HH:mm，默认 07:00，北京时间；旧配置兼容 |
| 刷新调度 | 分页查询 → leader gate → 4账号批次 → 现有 real_forward → extra | 每页100完整扫描；执行前重读；成功每日去重；窗口解除补跑；失败最多3次 |
| 自动选模 | 本地策略投影 / 可用快照 → 文本能力筛选 → 轻量/价格排序 | 使用展示ID请求，以目标身份识别家族；不扩大白名单 |
| 模型目录 | 官方文档 → 注册表/目录/价格种子 → 原生成器 → 前端快照 | 增量补齐；保留自定义覆盖；专用未接入协议仅收录，不加入公开可调用快照 |
